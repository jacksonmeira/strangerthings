# Stranger Things — The Experience

Página promocional inspirada na experiência imersiva de *Stranger Things*. O projeto apresenta as cidades participantes, depoimentos e informações da experiência em uma página com identidade visual temática e adaptação para dispositivos móveis.

## Sobre o projeto

Este site foi desenvolvido como projeto de estudo de front-end. A ideia foi praticar a criação de uma página de divulgação com imagens em destaque, seções organizadas e animações durante a navegação.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- GSAP e plugins ScrollTrigger, ScrollSmoother e SplitText

## Como visualizar

1. Faça o download ou clone este repositório.
2. Abra o arquivo `index.html` no navegador.

As animações GSAP e a fonte Poppins são carregadas por serviços externos, então alguns efeitos e a fonte podem não aparecer sem conexão com a internet. O conteúdo principal da página continua disponível.

## Estrutura

```text
├── fontes/       # Fonte usada no título
├── imagens/      # Imagens e logotipos do projeto
├── index.html    # Estrutura da página
├── script.js     # Animações
└── style.css     # Estilos e responsividade
```

## Observação

Projeto independente para fins de estudo e portfólio. *Stranger Things* e seus elementos visuais pertencem aos respectivos titulares.
